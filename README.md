# Environmental Advocacy & Community Evidence Gathering

*From Environmental Concern to Community Action: Building Evidence for Change*  
**Presenter: Sheriffdeen O. Saula**

A 16-slide interactive, responsive presentation deck built with Vite, React, and Tailwind CSS using Dattego's neobrutalist design system.

## ✨ Features
- **16 Polished Presentation Slides**: Covering conceptual foundations, the 7-stage advocacy lifecycle, taxonomy of evidence, the WaveWise case study, and operational toolkits.
- **Responsive Canvas Scaling**: Standard 1920x1080 presentation canvas automatically scaled down to fit desktop, tablet, and mobile screens.
- **Interactive Deck Controls**:
  - `←` / `→` or `Spacebar` for next/previous slides
  - `G` for thumbnail Grid View
  - `F` / `F5` for Fullscreen Present Mode
- **Lightweight Export Engine**:
  - **Export PDF**: Generates compressed high-fidelity PDFs via `jsPDF`.
  - **Export ZIP**: Fast slide image zipping powered by the ultra-lightweight `fflate` engine (~8KB).

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Start local development server
pnpm dev

# Build for production (outputs static files to dist/)
pnpm build
```
